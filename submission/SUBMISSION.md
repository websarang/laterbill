# 스킬톤 제출 원고

## 기본 정보

- 스킬 이름: `하다 만 일 종결반 (Laterbill)`
- 제작자명: `에이스`
- 한 줄 설명:

> 로컬 AI 대화에 남은 미완료 업무를 추적하고, 세 가지 실행 가능한 종결안을 제시하는 상환 에이전트입니다.

## 심사·갤러리 설명 본문

### 회고의 반대편을 만들었습니다

대부분의 회고 도구는 완료한 일을 요약합니다. Laterbill은 반대로, 시작했지만 끝내지 않은 일을 찾아냅니다. 사용자가 TODO를 미리 적어둘 필요도 없습니다. Claude Code와 Codex를 사용하면서 이미 쌓인 로컬 대화 기록이 증거입니다. 어떤 프로젝트를 열었는지, 얼마나 많은 대화를 투자했는지, 다시 열었다가 몇 번 떠났는지, 마지막으로 무슨 말을 남겼는지를 읽습니다.

그 흔적을 회계 언어로 바꿉니다. 원금은 프로젝트에 투입한 대화 턴 수, 연체는 마지막 활동 이후 경과일, 이자는 하루 이상 침묵한 뒤 같은 프로젝트에 재진입한 횟수입니다. 재진입할 때마다 “어디까지 했더라”를 다시 구성해야 하므로 이자는 실제로 발생한 맥락 복구 비용입니다. 사용자가 직접 말한 기한이나 관측된 재방문 주기가 있을 때만 납부 기한을 냅니다. 근거가 없으면 비워둡니다. 60일 이상 돌아가지 않은 항목은 무조건 되살리지 않고 정식 탕감을 우선 권합니다.

### 이름만 보여주는 청구서에서 실제 복귀 도구로

미완료 항목의 이름과 내용만 보여주면 사용자는 다시 프로젝트를 찾아 헤매야 합니다. Laterbill은 각 항목에 런타임, 세션 ID, 프로젝트 경로, 경로 존재 여부와 마지막 활동 시각을 `source_refs`로 보존합니다. Codex는 `codex resume -C <project> <session-id>`, Claude Code는 해당 프로젝트에서 `claude --resume <session-id>`로 마지막 맥락을 다시 엽니다. 프로젝트가 이동되거나 삭제됐으면 실행되지 않을 명령을 만들지 않고 위치 복구를 첫 상환안으로 냅니다.

공유용 장부는 반대로 이 좌표를 전부 없앱니다. `--anonymize`를 적용하면 프로젝트 경로, 세션 ID, 재개 명령, 실제 이름과 인용문이 제거됩니다. 공개 데모와 제출 이미지는 합성 데이터만 사용했습니다.

### 한 줄 조언 대신 비교 가능한 상환안 세 개

각 청구에는 가능한 경우 세 가지 실질적으로 다른 안이 붙습니다. A 빠른 진전은 30분 안에 중단 지점을 재현하고 현재 상태와 다음 행동 하나를 확인합니다. B 장애물 해소는 인증·결제·권한 같은 막힌 조건, 필요한 입력 또는 반복 재작성 전에 유지할 기존 결과를 먼저 분리합니다. C 완결 우선은 프로젝트에 이미 정의된 테스트·빌드·완료 조건을 확인하고 이번 업무를 실제 종결 상태까지 가져갑니다.

세 안에는 첫 행동, 추천 근거, 시간 상자, 완료 조건과 선택 시 장단점이 들어갑니다. 같은 행동을 표현만 바꿔 세 번 반복하지 않습니다. 배포 직전에서 기록이 끊긴 항목은 C, 장애물에서 끊긴 항목은 B를 추천하는 식으로 마지막 대화와 정지 신호에 근거합니다. 근거가 부족하면 억지로 세 개를 채우지 않습니다. 프로젝트가 없으면 위치 복구안 하나만 내고 “추가 상환안을 만들 근거가 부족함”이라고 밝힙니다.

사용자가 하나를 선택하면 README·AGENTS.md·CLAUDE.md, Git 상태와 최근 커밋, 마지막 대화에서 언급된 파일, 테스트·빌드 설정을 읽기 전용으로 점검합니다. 선택된 안만 대상 파일 또는 영역, 실행 행동, 완료 조건을 가진 최대 세 개 작업으로 상세화합니다. 분납은 첫 작업 하나와 30분만 남기고, 탕감은 실행 작업을 만들지 않고 결정과 사유만 기록합니다.

### 상환 뒤에는 자가개선이 남습니다

일을 한 번 끝내는 데서 멈추지 않습니다. 선택한 상세계획에는 `observed_pattern`, `guardrail`, `checkpoint`, `success_signal`, `review_after`로 구성된 자가개선 루프가 붙습니다. 예를 들어 배포 직전 중단이 반복됐다면 “배포가 두려웠다”고 마음을 추측하지 않습니다. 대신 다음 작업 시작 시 완료 기준에 빌드·테스트·배포 확인 순서를 넣고, 첫 작업 뒤와 세션 종료 전에 확인하며, 검증 결과와 장부 상태가 남았는지를 개선 신호로 삼습니다. 사람의 성격이 아니라 작업 흐름을 개선합니다.

### 안전 규칙이 문구가 아니라 실제 동작입니다

Laterbill의 기본 동작은 읽기 전용·로컬 전용입니다. 상환안을 만들 때 프로젝트 파일을 바꾸지 않습니다. 상세계획을 사용자에게 보여주고 승인받기 전에는 파일 수정, 명령 실행, 배포를 하지 않습니다. 이메일·토큰·전화번호·주민번호·홈 경로는 인용 전에 마스킹합니다.

건강·가족·금전·고용처럼 사적인 내용이 감지되면 경고문 뒤에 원문을 노출하는 방식이 아닙니다. `sensitive_approved`가 거짓인 동안 원문과 상환안 자체를 렌더링하지 않습니다. 내용도 다시 읊지 않고 “사적인 사안이 하나 잡혔는데 포함할까요?”까지만 묻습니다. 승인은 선택한 항목 ID 하나에만 적용됩니다.

대화가 부족하면 `insufficient_data`, 미납이 없으면 `no_debt`로 발행을 거부합니다. “게을러서”, “회피해서”, “두려워서”처럼 기록에 없는 동기나 성격을 진단하지 않습니다. 자책 반응이 나오면 상환 압박을 멈추고 분납이나 탕감을 먼저 제시합니다.

### 재현 가능한 완성도

최신 Codex의 `session_meta → turn_context → response_item` envelope와 Claude Code의 직접 메시지 형식을 각각 파싱합니다. 런타임별 발견 파일 수, 읽은 파일 수와 실제 파싱 대화 수를 따로 보고합니다. 표준 라이브러리만 사용해 추가 설치가 없고 Windows와 POSIX 경로를 함께 처리합니다. PowerShell의 네이티브 파이프 인코딩 차이도 통합 실행기로 우회합니다.

`python laterbill/scripts/selftest.py` 한 줄로 34개 검증을 실행합니다. 최신 Codex 파싱, source_refs, 자동·수동 발행 분리, 익명화, 상환안 세 개의 차별성, 배포·장애물별 추천, 근거 부족 시 생성 거부, 상세계획 최대 세 작업, 분납 한 작업, 탕감 0작업, 민감 원문 승인 전 숨김, 항목별 승인, 자가개선 가드레일, 프로젝트 무변경, HTML 주입 차단과 네트워크 라이브러리 부재를 실제 코드로 검사합니다.

공개 실행 증거는 개인 기록이 아니라 합성 fixture만 입력으로 사용한 실제 코드 실행입니다. 제출 직전 `python tools/verify-release.py`를 연속 두 번 실행했습니다. 이 명령은 현재 Skill에서 34개 테스트를 실행하고, allowlist로 ZIP을 새로 만든 뒤, 임시 폴더에 압축을 풀어 그 사본에서 같은 34개 테스트를 다시 실행합니다. 두 실행에서 ZIP 해시는 같았습니다.

```text
source:     34/34 통과
fresh ZIP:  34/34 통과
ZIP:        13 files · 67,350 bytes
SHA-256:    c3a8e282cea3af1311ba6466c5c43e3589c4db769abd06743ab88d52e8fe4d63
read-only:  README.md before SHA-256 == after SHA-256 · true
public:     source_refs=[] · project=<anonymized> · item_id=lb_public_a
```

복귀 명령도 같은 검증기에서 합성 fixture로 실제 호출했습니다. 출력은 `codex resume -C "C:\demo\sample-project" "demo-codex-001"`와 `cd "/demo/sample-project" && claude --resume "demo-claude-001"`였습니다. 개인 대화 기록은 사용하지 않았습니다. 전체 로그와 재현 명령은 `docs/assets/proof/release-verification.txt`에 함께 공개합니다.

Laterbill은 사용자를 심판하는 청구서가 아닙니다. 잊힌 일을 눈앞에 놓고, 돌아갈 좌표와 선택 가능한 경로를 제공하며, 끝낼 것과 놓아줄 것을 사용자가 결정하게 하는 반려 에이전트입니다.
